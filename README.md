# CEYLON — Beyond the Ordinary

A luxury Sri Lanka tourism website built with Next.js App Router, TypeScript, Tailwind CSS v4, Framer Motion and Lucide icons.

## Run locally
1. Install Node.js 20.9 or newer.
2. Extract this ZIP and open the folder in VS Code.
3. Open a terminal in the project folder and run `npm install`.
4. Run `npm run dev`.
5. Visit `http://localhost:3000`.

## Pages
- `/` homepage
- `/destinations` filterable destination directory
- `/destinations/[slug]` destination details
- `/itineraries` trip listings and duration filter
- `/itineraries/[slug]` day-by-day itinerary
- `/experiences`, `/about`, `/contact`

## Before launch
Replace sample text and prices with verified details, review image licensing, connect the enquiry form to a backend, and verify all travel/seasonal information. Prices are examples, not quotes.
